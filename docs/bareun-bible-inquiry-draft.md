제목: 개인 성경 연구 웹앱에 바른성경 본문 사용 문의

안녕하세요, 한국성경공회 담당자님.

저는 개인적으로 "LogosFlow"라는 성경 연구 웹앱(비영리, 개인 프로젝트)을
만들고 있습니다. 현재 개역한글(개역한글판)을 기본 번역본으로 제공하고
있는데, 좀 더 현대적인 번역본으로 바른성경도 함께 제공하고 싶어 문의드립니다.

문의드리고 싶은 내용은 다음과 같습니다:

1. 바른성경을 온라인/앱 서비스에 사용할 경우 저작권 사용료가 있는지,
   있다면 개인/비영리 프로젝트에도 동일하게 적용되는지 궁금합니다.
2. 사용이 허가된다면, 성경 본문 전체(66권, 장·절 단위 텍스트) 데이터를
   전자 파일(텍스트/JSON 등) 형태로 받을 수 있는 방법이 있을까요?
3. 사용 시 지켜야 할 조건(출처 표시, 본문 변경 금지 등)이 있다면 안내
   부탁드립니다.

[여기에 앱 소개/URL을 추가하세요: 예 https://github.com/BenSong92/logosflow]

감사합니다.

## 코드 쪽 준비 상태

`types/bible.ts`의 `TranslationCode`와 `lib/data/translations.ts`에 `"BRB"`
(바른성경) 항목을 이미 추가해뒀어요. 지금은 개역개정/현대인의성경과 같은
"잠김(pending-license)" 상태라 화면에는 안 보이거나 잠금 표시로만 떠요.

실제 텍스트 데이터를 받으시면:
1. `public/bible-data/BRB/` 폴더에 `GEN.json`, `EXO.json` ... 등 66개 파일을
   기존 `KRV/` 폴더와 똑같은 형식(챕터 배열 → 절 배열 → 문자열)으로 넣고,
2. `lib/data/translations.ts`의 `BRB` 항목 `licenseStatus`를
   `"free-attribution"`(또는 해당하는 상태)으로 바꾸면 끝이에요.

나머지(검색, 원어 연동, AI 기능 등)는 전부 이미 다른 역본을 지원하도록
만들어져 있어서 자동으로 작동해요.
